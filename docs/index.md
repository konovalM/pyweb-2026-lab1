# Predictive Sensorics · Публикация результатов исследований

Сайт-витрина результатов исследований компании **«Предиктивная сенсорика»**
по прогнозированию технического состояния промышленного оборудования на основе
данных вибродиагностики.

Сайт собран генератором статических сайтов **MkDocs + Material** в рамках
лабораторной работы по курсу «Проектирование и развертывание веб-решений в
эко-системе Python» и опубликован двумя путями:

- **GitHub Pages** — через GitHub Actions (`upload-pages-artifact` + `deploy-pages`);
- **Отечественный хостинг (Selectel)** — деплой по SSH с healthcheck.
